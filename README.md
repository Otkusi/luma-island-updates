# Luma Island — обновления

**1.5.1 исправляет ошибку Redirect was cancelled.** Версии 1.5.0 требуется ручная установка исправления: прежний загрузчик не может скачать его самостоятельно.

Здесь размещаются готовые выпуски Luma Island для Windows x64 и подписанное описание последней версии. Настройки приложения и история буфера обмена сюда не отправляются.

Начиная с 1.5.1: **Настройки → Ещё → Обновления → Проверить обновления**. Доступный выпуск устанавливается кнопкой **«Установить и перезапустить»**. Автоматическая проверка при запуске отключается рядом; установка начинается только по нажатию.

Для перехода с 1.5.0 и более ранней версии нужно один раз установить архив 1.5.1. Закрой остров через трей, распакуй полный ZIP в папку с прежним Luma Island.exe и запусти Install-Luma-NewFolder.cmd. Затем открой приложение из созданной папки Luma-1.5.1-…. Настройки сохраняются.

Приложение проверяет подпись Ed25519 и контрольные суммы файлов. Закрытый ключ подписи не хранится в этом репозитории. Новые версии создаются в отдельной папке; прежняя рабочая версия сохраняется.
